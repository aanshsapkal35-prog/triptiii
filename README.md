# 100 Things About You — HTML Edition

A cinematic, browser-based typography animation made with plain HTML, CSS and JavaScript.

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Upload `index.html`, `style.css`, and `script.js` to the root of your GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Choose branch **main** and folder **/(root)**, then Save.
5. Wait a minute and open the Pages URL shown there.

No Python or build tools required. The page uses Google Fonts for typography; it still works with fallback fonts if offline.
